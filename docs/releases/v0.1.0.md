# Edo Tensei v0.1.0

**Status:** Technical preview / experimental

Edo Tensei v0.1.0 demonstrates same-host checkpoint and restore of live AI
workloads.

## Validated environment

- Ubuntu 24.04 x86_64
- NVIDIA H100 80 GB
- CUDA 12.8
- CRIU 4.2.1
- One GPU and same-host restore

## Included

- Linux x86_64 `edo` binary
- CPU checkpoint/restore onboarding path
- Experimental CUDA and vLLM process-group integrations
- Documentation at <https://tsdocode.github.io/edo-tensei/>

## Scope and limitations

Async vLLM requires the Edo CRIU fork with io_uring support. Kubernetes
support is an experimental same-node, container-aware prototype. Cross-node
migration, in-flight request preservation, universal GPU compatibility,
guaranteed KV-cache preservation, and a production Kubernetes operator are not
promised by this release.

See the [compatibility matrix](../compatibility.md), [vLLM guide](../integrations/vllm.md),
and [Kubernetes guide](../integrations/kubernetes.md) before testing.
